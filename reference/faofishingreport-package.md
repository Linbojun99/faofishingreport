# faofishingreport: Analyse and Report FAO Global Capture Production Statistics

Analyses FAO Global Capture Production statistics by fishing area,
country and species, and exports charts (PNG and editable PowerPoint)
and tables for reports. Includes breakpoint analysis of catch time
series, checks for and downloads the latest FAO data release, and draws
charts in English, Chinese or both, using official FAO Chinese names and
a Chinese font chosen for the operating system. Runs the catch-only
stock assessment method CMSY++ (Froese et al. 2023
[doi:10.3897/aiep.53.105910](https://doi.org/10.3897/aiep.53.105910) )
on the catch series, with the bundled CMSY++ code, priors from FishBase
and SeaLifeBase, and JAGS installed and the code adapted for the
operating system.
